# Collect submissions in the Entry Hub

The Entry Hub keeps each team, deck and note in one project. Use manual entry, a team submission page, or both.

## Choose an intake method

<!-- widget:cards plain cols=2 -->

- Add manually — When applications already arrive through another tool. Enter the team name, project, deck and an optional note for the jury. {keyboard}
- Publish a submission page — When teams upload their own material. Share one link; teams sign in with Google and submit directly. {globe}

<!-- /widget -->

## What an entry contains

| Field | Rule |
|---|---|
| Pitch deck | PDF, PPT, PPTX or Google Slides link; one deck per team; up to 50 MB |
| Team and project details | The identifying fields configured for the project |
| Note for judges | Optional context from the team |
| Status | `ready`, `incomplete` or `submitted` |

## Configure the submission page

- **Preview** the page before sharing it, and **publish** only once the requirements are final.
- **Restrict access** to approved email addresses, or accept anyone with the link.
- **Set the submission window**; close it before judging if later arrivals belong to another run.
- **Share the link or QR code** through the channels your teams use.
- **Link invites automatically** — add a team email, and a Google sign-in with that address attaches the submission to the invite.

## Check readiness

The project page counts entries that are ready, incomplete and still need attention. Resolve exceptions before launching.

A run can start once at least one entry is `ready`. Incomplete entries are not silently included.

## Tell applicants about AI

State on the form that EvalLens assists the first read, applies the same rules to every entry, and does not make the final ranking. Link [For applicants](./for-applicants.md) for teams that want the detail.
