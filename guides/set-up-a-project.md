# Set up an EvalLens project

A project represents one selection round. Its mode determines the panel; the wizard then configures the round.

## Choose the mode first

| Mode | Panel | Rubric |
|---|---|---|
| Pitch Competition | Six judges | Six dimensions, P1–P6 |
| Hackathon | Five reviewer roles | Execution-weighted rubric |

Choose the mode that matches the decision. Do not use a pitch rubric for a round where technical execution is the main question.

<!-- widget:stepper -->

### Enter the event details

Add the project name, program information and dates. These details appear on the submission page, so write them for applicants.

### Set criteria and weights

Review the default rubric and change the weights before scoring begins. The default pitch weights are:

- **P1 Problem** — `0.15`
- **P2 Solution** — `0.15`
- **P3 Market** — `0.20`
- **P4 Business model / GTM** — `0.15`
- **P5 Team** — `0.20`
- **P6 Feasibility** — `0.15`

The [criteria and weights reference](./criteria-and-weights.md) explains the anchors and the lock.

### Review the judge configuration

The mode supplies the panel and routing. Each judge contributes at a defined level: primary, secondary, advisory or not scored.

See [The six judges](../scoring/judges.md) for the routing matrix.

### Choose how teams enter

Add teams manually, publish a submission page, or use both. The [collection guide](./collect-submissions.md) covers access, deadlines and readiness.

### Complete the final review

Check the rubric, submission requirements, deadline and reviewer process. Confirm that your rules explain what the AI panel assists with and what human judges decide.

<!-- /widget -->

## Before you launch

- The mode matches the program.
- The weights match what the jury will discuss.
- The submission page states required materials and deadlines.
- Reviewers know who sets the Jury Score.
- You have explained AI assistance to applicants.

## What locks later

Weights freeze when scoring starts. A published submission page may already be shared, so preview it before publishing.
